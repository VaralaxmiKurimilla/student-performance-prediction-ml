# Student Performance Prediction Using Machine Learning

## Project Overview
This project predicts students' final academic grades using Machine Learning techniques. It analyzes academic and personal factors to understand student performance and identify students who may need additional academic support.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Dataset
- **Source:** UCI Machine Learning Repository
- **Records:** 395 students
- **Features:** 33 columns
- **Target Variable:** G3 (Final Grade)

## Machine Learning Algorithms
1. Linear Regression
2. Random Forest Regressor

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Selection
5. Model Training and Testing
6. Model Evaluation
7. Model Comparison

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Results
Random Forest Regressor performed better than Linear Regression.

| Model | R² Score |
|---|---:|
| Linear Regression | 0.724 |
| Random Forest | 0.815 |

## Files Included
- `ML_Project.ipynb` – Python implementation of the project.
- `Student Performance Prediction Using Machine Learning.pdf` – Project presentation.

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells sequentially.
3. View the analysis, graphs, model training and evaluation results.

## Conclusion
The project demonstrates how Machine Learning can be used to predict student academic performance. Random Forest achieved better results than Linear Regression on this dataset.
